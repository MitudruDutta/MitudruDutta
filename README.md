## 🔬 Featured Projects

### 🤖 LLMs & Reinforcement Learning
- **[ChargebackOps](https://github.com/MitudruDutta/chargebackops)** — An OpenEnv-compatible **RL environment** for credit-card chargeback disputes (13 typed actions, adversarial issuer, 8-dimension reward rubric, 113 tests). Post-trained Qwen2.5-3B with **SFT + GRPO (LoRA)** — +18% over base — and documented a reproducible specification-gaming failure mode. *Top 100, international hackathon.*
- **[ABSA — Aspect-Based Support-Ticket Router](https://github.com/MitudruDutta/ABSA)** — Fine-tuned a **RoBERTa** sentence-pair classifier over a 9-aspect taxonomy on 20K tickets (human-audited labels, Cohen's κ 0.71). **Macro-F1 0.843**; proved one shared model beats 10 per-queue specialists on 10/10 queues. FastAPI + Streamlit, Dockerized.

### 🧠 Applied AI & RAG
- **[MediRep AI](https://github.com/MitudruDutta/MediRep-AI)** — Multimodal medical intelligence platform over a 250K+ drug database with RAG grounding (image + text + structured data). *$100 prize, national hackathon grand finale.* &nbsp;[live demo](https://medirep-ai.vercel.app/)
- **[PaperQA — PDF Intelligence](https://github.com/MitudruDutta/paper)** — QA backend over user-uploaded PDFs with page-level citations and strict grounding, plus evaluation hooks for retrieval quality.
- **[Hybrid Telecom Agent](https://github.com/MitudruDutta/Hybrid_Telecom_Agent)** — Production AI agent that routes queries between vector-search FAQ and SQL analytics; built for AWS Bedrock AgentCore with conversation memory.

### 📊 ML, Forecasting & Computer Vision
- **[Predicting Stellar Class](https://github.com/MitudruDutta/Predicting-Stellar-Class)** — Kaggle stacking ensemble (XGBoost/LightGBM/CatBoost) with a **TabPFN-3 meta-learner**; balanced accuracy **0.9676**.
- **[DamageX](https://github.com/MitudruDutta/damagex)** — Vehicle damage classifier: fine-tuned **ResNet-50** with a ResNet-18 gatekeeper rejecting non-vehicle images. FastAPI + Next.js.
- **[Credit Risk Modelling](https://github.com/MitudruDutta/CreditCard-Risk-Modelling)** — End-to-end credit-default scoring (Optuna-tuned XGBoost, **AUC 0.98**) deployed as a live Streamlit app. &nbsp;[live demo](https://creditxrisk.streamlit.app/)
- **[Healthcare Premium Prediction](https://github.com/MitudruDutta/Healthcare-Premium-Prediction)** — Age-segmented regression models for insurance premiums, deployed on Streamlit.

### 🛠️ Tooling
- **[distill](https://github.com/MitudruDutta/distill)** — Any document → clean Markdown in a single Go binary (PDF, DOCX, XLSX, EPUB, audio, video). Built for LLM/RAG pipelines, MCP-native.
